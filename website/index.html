⚡

In-Memory Session Manager

The SessionManager static singleton class holds the authenticated user globally in memory across screens, preventing prop drilling while keeping screen transitions instantaneous.

🛡️

Android 13+ Photo Picker Sandbox

When picking profile photos, the image is automatically copied to the application's private documents directory via path_provider, preventing temporary URI permission revocation on modern Android versions.

🔒

Safety Guard Account Deletion

Permanent account deletion requires the user to explicitly type "DELETE" in uppercase. On verification, it synchronously drops rows from both users and login tables, purges session state, and redirects safely to the splash screen.

🎨

Material-3 Edge-to-Edge Design System

Crafted with Google Fonts (Aboreto display text, Poppins body text), soft card elevation, teal brand gradients, and sticky Table of Contents that dynamically adapts across orientations.
